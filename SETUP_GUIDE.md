# CRICKSTATS Salesforce Setup Guide

The uploaded specification requires these milestones:

1. Create a Salesforce Developer org.
2. Deploy Player and Match Performance objects.
3. Create tabs for Players and Match Performances.
4. Create Lightning App: CRICKSTATS.
5. Add Players, Match Performances, Reports and Dashboards to navigation.
6. Create/configure Player and Match Performance page layouts.
7. Activate roll-up summary fields on Player.
8. Create Screen Flow `Player Flow`:
   - Screen: team picklist
   - Get Records: Player records filtered by selected Team
   - Data Table: Profile Picture, Player Name, Total Runs, AVG Score,
     Batting Style, Bowling Style, Matches Played, Number of 50's, Number of 100's
9. Add the Player Flow to the CRICKSTATS Home page.
10. Create reports and dashboard components.

The source document describes the same flow and navigation sequence in its development phase.
